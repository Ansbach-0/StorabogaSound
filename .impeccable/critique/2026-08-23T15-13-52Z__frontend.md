#### Priority Issues

- **[P1] DEF-01: Keyboard Shortcut Collision on Custom Form & Role Controls**
  - *Why it matters*: Pressing `Space` inside a switch or tab toggles the control and triggers global audio pause simultaneously.
  - *Fix*: Guard global `keydown` against `e.defaultPrevented` and role targets (`[role="switch"]`, `[role="tab"]`, `[role="button"]`).
  - *Suggested command*: `/impeccable harden`

- **[P1] DEF-02: Mobile Stacking & Above-the-Fold Loss**
  - *Why it matters*: On mobile viewports, the 24-slot roster wall pushes the Now Playing hero showcase and playback controls ~800px below the fold.
  - *Fix*: On mobile (`< lg`), prioritize Now Playing Showcase at the top and cap empty queue slots to 6.
  - *Suggested command*: `/impeccable adapt`

- **[P1] DEF-03: Silent Error Swallowing on Playback & Volume Actions**
  - *Why it matters*: If a non-moderator clicks pause/volume or the server rejects an action, empty `catch {}` leaves the user with zero feedback.
  - *Fix*: Display an ephemeral notification/toast on failed API mutations.
  - *Suggested command*: `/impeccable harden`

- **[P2] DEF-04: Layout Property Animation in Playback Progress Bar**
  - *Why it matters*: `transition: width` causes layout thrashing during progress updates.
  - *Fix*: Use `transform: scaleX(progress)` with `transform-origin: left`.
  - *Suggested command*: `/impeccable optimize`

- **[P2] DEF-05: Micro-Typography Legibility Floor**
  - *Why it matters*: Labels using `text-[8px]` and `text-[9px]` fail accessibility legibility standards.
  - *Fix*: Elevate functional text to a minimum of `11px`.
  - *Suggested command*: `/impeccable typeset`

- **[P2] DEF-06: Telemetry Equalizer Re-render Thrash**
  - *Why it matters*: A 1s `setInterval` in `StatusHideout.tsx` triggers full component re-renders to animate 32 equalizer bars.
  - *Fix*: Replace state-driven bar height calculation with pure CSS keyframe animations.
  - *Suggested command*: `/impeccable optimize`

- **[P2] DEF-07: Single-Click Destructive Voice Disconnect Guard**
  - *Why it matters*: Accidental click on the skull button abruptly kicks the bot and wipes the queue.
  - *Fix*: Add a confirmation step ("Click again to confirm disconnect").
  - *Suggested command*: `/impeccable harden`

- **[P3] DEF-08: Non-standard Tailwind utility in HistoryArchive**
  - *Why it matters*: `group-hover:scale-102` is non-standard in default Tailwind.
  - *Fix*: Replace with `group-hover:scale-[1.02]`.
  - *Suggested command*: `/impeccable polish`
